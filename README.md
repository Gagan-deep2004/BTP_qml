# Q-ITS: Quantum-Enhanced ITS for Urban Traffic — Reproduction and Extension

B.Tech Project (BTP), NSUT Delhi.

**Base paper:** H. Ahmad et al., "Quantum-Enhanced ITS Leveraging Consumer Devices for Real-Time Urban
Traffic Optimization in Smart Cities", *IEEE Transactions on Consumer Electronics*, vol. 72, no. 1,
pp. 2540–2548, Feb. 2026. The paper has no public code, so everything here was written from scratch.

The project has two parts:

1. **Base implementation (`base_imp/`)**: a faithful reproduction of the paper. Consumer-device traffic
   data, a 4-qubit variational quantum circuit (VQC) per intersection for routing, BB84 QKD with
   one-time-pad messages, trust-weighted quantum consensus, and the paper's baselines (fixed-time,
   rule-based, DQN).
2. **Novelty (`novelty_imp/`)**: improvements to the **traffic-optimisation side only**  *(Not in this repository yet; it will
   be added later. The sections below that mention `novelty_imp/` apply once it is.)*

## Setup

Python 3.12.

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows  (Linux/macOS: source .venv/bin/activate)
python -m pip install -r requirements.txt
```

## Running

**Base implementation.** Run from inside `base_imp/`:

```bash
cd base_imp
python -m pytest -q                                   # tests
python -m experiments.generate_dataset                # vehicle demand   -> data/demand/
python -m experiments.generate_device_data            # 16 features      -> data/devices/
python -m experiments.run_baselines                   # fixed-time, rule-based, DQN
python -m experiments.run_qits                        # Q-ITS
python -m experiments.make_figures                    # tables + figures -> results/figures/
```

**Novelty** (once `novelty_imp/` is added). Run from the project root:

```bash
python -m pytest novelty_imp/tests -q                 # tests (includes a check that base_imp is unchanged)
python -m novelty_imp.experiments.generate_scenarios  # peak / directional / rush demand
python -m novelty_imp.experiments.run_eval --seeds 30 # evaluate controllers on all scenarios
python -m novelty_imp.experiments.report_v2           # summary table -> novelty_imp/results/eval/v2_summary.md
```

Each script's docstring lists its options.

## Data

All data is synthetic, generated by the simulator. The paper does not release a dataset.

- **Network:** a 5×5 grid of intersections with 100 m two-lane roads (the paper uses 50×50; see the guide).
- **Demand** (`data/demand/<density>/seed_<n>.csv`): Poisson vehicle arrivals at low / medium / high
  density (30 / 60 / 90 % of capacity) with random origin–destination pairs. Seeds 42–71 (30 seeds).
- **Device features** (`data/devices/<density>/seed_<n>.npz`, key `x`, shape 1800 s × 25 × 16): for each
  of the 4 incoming roads, **density, speed, queue and predicted inflow**, estimated from the 60 % of
  vehicles that carry a phone or in-car unit. 16 = 4 roads × 4 features, the 2⁴ amplitudes of 4 qubits.
  The paper only names "density, speed and prediction-horizon features"; this exact choice is ours.
- `probes_seed_42.parquet/.csv`: the raw per-second device reports that the features are built from.
- **SUMO dataset** (`sumo_data/`): the same kind of data generated with the SUMO traffic simulator on a
  25×25 grid (625 intersections). The data itself (4.1 GB) is not in git; `sumo_data/README.md` explains
  how to regenerate it (`bash run_all.sh`). Calibrated saturation rate: 9.28 veh/s.

## Key results

**Reproduction** (`base_imp/results/figures/`): Q-ITS reduces average delay by 9.8 % vs rule-based
control (paper: 42.1 %), but a standard DQN signal controller is better than Q-ITS. The quantum
communication layer works as described (mean entanglement fidelity 0.918, paper > 0.90). Several of the
paper's numbers could not be reproduced; see `docs/Q-ITS_Base_Paper_Reproduction.pdf`.

**Novelty** (`novelty_imp/results/eval/v2_summary.md`, 30 test seeds): PQ-ITS cuts delay by 30–40 % vs
base Q-ITS at low and medium density and matches max-pressure, but still gridlocks under peak, high
demand. The same-size classical network does as well as the quantum circuit or slightly better. Work in progress.
